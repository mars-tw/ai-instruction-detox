# 03 — Maßnahmen für Regeln

Jede Regel erhält genau eine Maßnahme; kein stillschweigendes Löschen.

| Rule ID | Ursprüngliche Position | Maßnahme | Begründung | Neue Position/Ersatzregel | Verhaltenswirkung | Rollback | Status |
|---|---|---|---|---|---|---|---|

KEEP, REWRITE, MERGE, MOVE, DELETE, ARCHIVE, QUARANTINE, AUTOMATE, HUMAN_REVIEW, TEMPORARY.
