# 言語版とインストール

`zh-TW`、`en`、`de`、`ja` の 4 言語を提供します。中国語のルート文書が翻訳元です。意味と安全上の契約は
同じバージョンで維持します。翻訳は読解／実行用の版であり、権限を追加したり、ソースと正本を競合させたりしません。
同名の 4 つのスキルをホストに同時に自動読み込みさせないでください。

## 完全な範囲

各言語は README、SKILL、CHANGELOG、AUDIT-REPORT、すべての references と templates を含みます。
自然言語の説明とテンプレートのラベルは翻訳します。コード、コマンド、ファイル名、JSON keys、schema version、CSV header、
状態 enum、rule ID、テンプレート変数、外部 URL は同一に保ちます。
ソース文書の過去のテスト結果を維持します。限られた実測を、すべての言語／プラットフォームが検証済みであるという主張に変えてはいけません。

ソース内の翻訳文書は `locales/en`、`locales/de`、`locales/ja` にあり、ツールとテストは一つだけで、
ルートの `scripts/`、`tests/` で管理します。locale のメインスキルを直接読む場合、コマンドは repo のルートから実行してください。
locale フォルダーだけをコピーしても、実行可能な完全なスキルにはなりません。

## リリースパッケージ

```powershell
python scripts/build-locales.py --output-dir release-packages-new
```

このビルドコマンドは、完全なソース repo のルートから実行します。リリース ZIP には選択した言語の文書、実行ツール、テストだけを含み、他言語や開発用の build-locales.py は含みません。ZIP は多言語のソース checkout ではありません。

出力ディレクトリは新規である必要があります。4 つの ZIP、SHA256SUMS.txt、RELEASE-MANIFEST.json を生成します。
各 ZIP のトップレベルは `ai-instruction-detox/` で、その言語の文書、テンプレート、共通ツール、テスト、
`package-language.json` を含みます。明示された公開ファイルだけを収録し、Git、staging、バックアップ、個人用のパス、認証情報は含みません。
パッケージ内の言語切り替えリンクは GitHub の対応する版を指し、インストールされていない他の言語の文書に依存しないようにします。

ダウンロードして SHA-256 を確認した後、完全なフォルダーをホストのスキルディレクトリに配置します。ホスト自身の読み込み／更新方法を使用し、
すべての製品のインストールディレクトリや自動読み込み構文が同じだと仮定しません。更新前に既存のスキルの変更と復元可能なコピーを維持します。
同名のメインスキルを四つ同時にインストールしないでください。言語を変える場合は、先にソースバージョンを照合してから完全なパッケージを交換します。

## ツールの言語

スキャナーとナビゲーションツールは `--language zh-TW|en|de|ja` を受け付けます。未指定の場合、ツールがあるスキルパッケージの
`package-language.json` を使用します。ソースの既定は繁体字中国語です。監査対象ディレクトリ内の metadata を読まず、OS の
環境から推測しません。CLI の表示テキスト、概要、生成されるナビゲーションラベルは変わりますが、機械用フィールド、ファイル名、終了コードは変わりません。

```powershell
python scripts/detox-scan.py --root . --language en
python scripts/project-map.py check --manifest project-map.json --language de
python scripts/project-map.py render --manifest project-map.json --output-dir map-preview-new --language ja
```

これらのフラグは、許可パス、スキャン範囲、書き込み境界、安全検査を変更しません。

## 保守と検証

ソースの契約を変更するたびに、関連する翻訳、テンプレート、バージョンを同期します。テストで完全な文書一覧、相対リンク、
テンプレート変数、機械用フィールド、コードコマンド、言語オプションを比較します。ファイルの存在確認だけで済ませず、独立したコンテキストによる意味のレビューも行います。
各言語の CLI は一時 fixture で実行します。リリース ZIP を展開した後、リソース、ツール、metadata を検証します。
実際に実行していない言語／プラットフォームの検査は NOT_RUN とし、翻訳が完成しただけで合格済みと主張しません。
