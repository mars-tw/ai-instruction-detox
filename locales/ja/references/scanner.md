# スキャナーの契約

`scripts/detox-scan.py` は Python 3.8 と互換性のある構文と標準ライブラリを使用します。パッケージをインストールせず、ソース内容を実行せず、
参照先の内容を読みません。実際に検証済みの Python／プラットフォームのバージョンは今回の更新レポートを参照してください。

## 使用方法

```powershell
python scripts/detox-scan.py --root .
python scripts/detox-scan.py --files SKILL.md references/apply-phase.md
python scripts/detox-scan.py --root . --json scan-new.json
python scripts/detox-scan.py --root . --max-depth 8 --max-bytes 2097152
```

`--root` と `--files` はどちらか一つを必ず選択し、同時には使用できません。ホームディレクトリやファイルシステムのルートを
再帰スキャンの対象にできません。明示的なファイル一覧でも、機密位置、リンク、通常ファイル以外のファイルを拒否します。
`--json` は新規ファイルだけを作成できます。親ディレクトリは存在している必要があり、ソース、古いレポート、リンクを上書きできません。

既定の深さは 6（ルートは 0）、単一ファイルは 1 MiB、最大 5,000 ファイル、読み取り総量は 64 MiB です。
UTF-8／UTF-8 BOM を読み取れます。不正なエンコード、不存在、読み取り不可、変動中のファイル、深さやサイズによる打ち切りは
coverage error として記録し、スキャン済みとみなしません。

| 終了コード | 意味 |
|---:|---|
| 0 | 選択範囲の読み取りが完了し、リスクパターンの検出なし。意味／安全の全面的な合格を示さない |
| 1 | 秘密、インジェクション、参照境界、参照切れ、循環候補、ファイル間重複の疑いあり |
| 2 | CLI／範囲／出力が無効、またはスキャン可能なファイルなし |
| 3 | 部分スキャン。まず不足を解消してから完全性を判断 |

## 検出と制限

- すべての検出は位置、分類、必要な統計だけを含み、ソースの抜粋、秘密の値、元の参照文字列を含みません。
- よくある接頭辞の key、GitHub fine-grained PAT、認証情報付き URL、秘密鍵のマーカー、一般的な認証情報の代入に対応します。
  あらゆる秘密の識別は保証できません。文書の防御例や禁止文も検出される場合があります。
- Markdown／backtick／一般的なプレーンテキストのファイル参照を解析し、URL とアンカーだけの参照は無視します。
  参照は `..` やリンクを経由してスキャン範囲を越えられません。参照が新たな内容の読み取りを引き起こすことはありません。
- 有向グラフの強連結成分を使って複数ノードと自己参照の循環を見つけ、各成分から代表的な循環を一つ提示します。
  すべての可能な循環を列挙するわけではありません。戻るナビゲーションリンクや例も検出されるため、本当に強制読み込みかどうか判断する必要があります。
- 重複の判断には正規化した段落全体を使用し、短縮した接頭部分を使用せず、段落内容も返しません。
- ファイルサイズと token の推定はスキャン量であり、ホストでの実際の自動読み込み量を示しません。
- 自動棚卸しは、コードで定義した入口名とルールディレクトリだけを対象にします。README、技術設定、未対応形式、
  外部にインストール済みのコピーは棚卸しチェックリストに従って別途確認してください。自動一覧をプロジェクト全体の完全な一覧とみなしてはいけません。

## JSON バージョン 2

`schema_version`、`files_selected`、`files_scanned`、`complete`、`errors`、`skipped`、`limits`、
`dangling_refs`、`boundary_refs`、`circular_refs`、`secrets`、`injections`、`vague_rules`、
`absolute_terms`、`duplicate_blocks`、`file_stats`。

`complete` は設定範囲内の読み取り成功だけを示します。ポリシーによる除外も `skipped` に記録します。
v1 の `snippet`、`text`、raw `ref`、2 ノードの `pair` は出力しなくなりました。レポートを使用するプログラムは更新が必要です。
循環は `files` と `cycle`、重複は `locations` と `characters` を読み取ります。

Python の呼び出しインターフェースは `find_files(root=None, explicit=None, max_depth=6)` と
`scan(files, root=None, max_bytes=1048576)` を維持します。一覧は list-compatible な `FileSelection` で、
`root`、`errors`、`skipped` を持ちます。`read()` の失敗はエラーを送出します。空ファイルとして扱うことはできません。

パスの安全検査は OS のサンドボックスではありません。実行時は、他のプロセスによる祖先ディレクトリの悪意ある置き換えを避ける必要があります。
このツールが並行するパス競合を完全に防御すると主張しないでください。
